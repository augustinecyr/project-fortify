Frontend · Dashboard UI
🎈
Streamlit
v1.53.1
Python-native web UI framework. Powers the dashboard — charts, controls, and data views — without writing any HTML/CSS/JS.
Port 8501 (default)
📊
Plotly
v6.5.2
Interactive charting library. Renders graphs, time-series, and visual analytics directly inside the Streamlit dashboard.
Visualisation
🐼
Pandas
v2.3.3
DataFrame engine. Cleans, transforms, and shapes data before it reaches Plotly or Streamlit tables. NumPy sits underneath for array ops.
Data Wrangling
API Layer · Backend
⚡
FastAPI
v0.128.0
High-performance async API framework. Handles HTTP routing, request validation via Pydantic, and auto-generates OpenAPI/Swagger docs.
Port 8000
🦄
Uvicorn
v0.40.0
ASGI server that runs the FastAPI app. Hot-reload in dev mode, handles async concurrency efficiently in production.
ASGI Server
🔷
Pydantic
v2.12.5
Data validation and settings management. Every API request/response schema is defined and enforced with Pydantic models at runtime.
Validation
🌐
HTTPX + Requests
0.25.2 / 2.32.5
HTTP clients. HTTPX for async outbound API calls from the backend; Requests used in the Streamlit frontend to call FastAPI endpoints.
HTTP Clients
Database · ORM · Migrations
🐘
PostgreSQL
v15 Alpine · Docker
Primary relational database. All persistent application data lives here. Health-checked — the API won't start until Postgres is ready.
Port 5432
🗂️
SQLAlchemy
v2.0.46
ORM layer. Database tables are defined as Python classes; SQLAlchemy handles query generation. No raw SQL needed in application code.
ORM
🔄
Alembic
v1.18.1
Database migration tool built on top of SQLAlchemy. Schema changes are versioned as migration scripts — safe upgrades and rollbacks without data loss.
Migrations
🔌
Psycopg
v3.3.2
PostgreSQL driver. The low-level adapter SQLAlchemy uses to open connections and execute queries against the Postgres container.
DB Driver
Caching · In-Memory Store
⚙️
Redis
v7 Alpine · Docker
In-memory key-value store. Used for caching API responses, managing sessions, and/or brokering background tasks. Data persisted via Docker volume.
Port 6379
🐍
redis-py
v5.0.1
Official Python client for Redis. FastAPI uses this to read/write cache keys, set TTLs, and interact with the Redis container programmatically.
Redis Client
