Phase 1 Current Implementation
Frontend · Dashboard UI
Streamlit v1.53.1
Python-native dashboard. Charts, tables, and controls without frontend code.
Plotly v6.5.2
Interactive charts and time-series visualisations inside Streamlit.
Pandas + NumPy
Data wrangling and transformation before rendering.
API Layer · Backend
FastAPI v0.128.0 · :8000
Async API framework. Routing, validation, OpenAPI docs auto-generated.
Uvicorn + Starlette
ASGI server + middleware layer running FastAPI.
Pydantic v2 + pydantic-settings
Schema validation for all requests, responses, and config.
HTTPX + Requests
Async and sync HTTP clients for outbound calls.
Database · ORM · Migrations
PostgreSQL 15 :5432
Primary relational store. All persistent data. Dockerised, health-checked.
SQLAlchemy 2.0
ORM — tables as Python classes, queries auto-generated.
Alembic
Versioned schema migrations. Safe upgrades and rollbacks.
Psycopg 3
Low-level PostgreSQL driver used by SQLAlchemy.
Caching · In-Memory
Redis 7 :6379
Cache, session store, and/or task queue broker. Dockerised, persistent volume.
redis-py v5.0.1
Python client for reading/writing Redis from FastAPI.
Testing · Code Quality
Pytest · pytest-asyncio · pytest-cov
Test runner with async support and coverage reporting.
Black · Flake8 · isort · mypy
Formatting, linting, import order, and static type checking.
Phase 2 → Upcoming Capabilities
AI · LLM Integration
Llama 3 / Mistral
Open-source LLMs for threat analysis, anomaly explanation, and natural language querying of security data.
Ollama / vLLM
Local model serving layer. Run LLMs on-prem without cloud dependency — important for sensitive security data.
LangChain / LlamaIndex
Orchestration framework for RAG pipelines, prompt chaining, and tool-use agents over security knowledge bases.
Vector DB (pgvector / Qdrant)
Embedding store for semantic search over logs, CVEs, and threat intel documents.
Orchestration · Scaling
Kubernetes (K8s)
Container orchestration for production. Auto-scaling, rolling deploys, self-healing pods across the full stack.
Helm Charts
Kubernetes package manager. Templated, version-controlled K8s manifests for Fortify's services.
Horizontal Pod Autoscaler
Automatically scales API and LLM inference pods under load.
Async Processing · Task Queue
Celery + Redis Broker
Distributed task queue for background jobs — LLM inference, report generation, scheduled scans.
Kafka / RabbitMQ
Event streaming for high-throughput security event ingestion and real-time pipeline processing.
Observability · Monitoring
Prometheus + Grafana
Metrics collection and dashboarding for API latency, model inference time, and infra health.
OpenTelemetry
Distributed tracing across FastAPI, LLM calls, DB queries — end-to-end request visibility.
Auth · Security Hardening
OAuth2 / JWT
Token-based authentication and role-based access control for the API.
Vault (HashiCorp)
Centralised secrets management. Replaces .env files in production K8s environment.
Infrastructure · Shared Across Both Phases
Docker + Compose now
Local dev orchestration. Single command spins the full stack.
Kubernetes upcoming
Production-grade container orchestration replacing Compose.
Python 3.11+ now
Core runtime across all backend services.
GitHub + GitPython now
Source control and repo interaction layer.
CI/CD Pipeline upcoming
GitHub Actions or ArgoCD for automated test, build, and deploy.
Cloud Provider upcoming
AWS / GCP / Azure for managed K8s (EKS / GKE / AKS) and GPU inference nodes.
