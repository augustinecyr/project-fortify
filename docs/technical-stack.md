# Technical Stack Overview

## Application Layer
- FastAPI (Python)
- REST-based APIs

## AI / Analytics
- scikit-learn (baseline models)
- PyTorch (future enhancements)
- Statistical anomaly detection

## Generative AI
- Open-source LLMs (e.g., Mistral / Llama)
- Used for explanation and summarization

## Data Layer
- PostgreSQL (metadata and results)
- Redis (optional caching)

## Infrastructure
- Docker for containerization
- Kubernetes-ready deployment
- Optional GPU acceleration

## Observability
- Prometheus (metrics)
- Grafana (visualization)

## Frontend
- Streamlit
